# SemMed-LDP Project Scope

## Project identity

- Project ID: `SemMed-LDP`
- Project type: independent research project and independent manuscript
- Working directory: this directory only

## Research objective

Study a medical-knowledge-guided framework for collecting semantically reduced
high-dimensional medical data under local differential privacy. A public prior
knowledge source processes attribute names and relations, while private user
values remain local.

## Intended pipeline

```text
attribute names
  -> public medical knowledge mapping
  -> task-specific semantic graph
  -> fixed semantic reduction rule
  -> local reduction of user values
  -> local differential privacy perturbation
  -> server-side aggregation and analysis
```

## In scope

- Mapping medical attributes to public medical concepts.
- Constructing a task-specific semantic graph from public prior knowledge.
- Deriving an interpretable, fixed semantic grouping or reduction rule.
- Applying established LDP mechanisms locally after semantic reduction.
- Comparing complete multidimensional reporting protocols independently of the
  semantic representation.
- Frequency/distribution estimation and other independently approved analysis
  tasks.
- Comparing multiple datasets, knowledge sources, grouping methods, LDP
  mechanisms, and privacy budgets.
- Evaluating statistical accuracy, compression, communication, stability,
  mapping coverage, and interpretability.

## Out of scope unless explicitly amended

- A preset PIC mortality-prediction objective.
- Any clinical label or prediction task inherited from another project.
- Privacy--utility theory, new error bounds, convergence proofs, or theoretical
  contributions imported from another project.
- Reuse of another project's code, preprocessing, cohorts, results, tables,
  figures, manuscript text, or conclusions.
- Central differential privacy, federated learning, or training a private
  dimensionality-reduction model.

## Data boundary

PIC may be used as an original experimental data source. If used, its cohort,
attributes, preprocessing, semantic states, and evaluation tasks must be defined
inside this project and generated by this project's scripts. No previous PIC
project decisions are inherited.

## Current manuscript positioning

The intended contribution is a public-medical-knowledge-guided, data-independent
semantic reduction workflow integrated with established LDP data collection.
The paper must not use an absolute "first KG + LDP" claim. Final novelty wording
must be supported by a documented literature search.

## Change control

Any addition to the scientific objective, downstream task, theoretical scope,
or external project dependency must first be recorded here with the user's
explicit approval.
